FINAL PROJECT

읽기에서 설명으로

논문 한 편의 핵심 계산이나 아이디어를 골라, 동료가 입력부터 결과까지 따라갈 수 있도록 설명합니다.

01

2인 팀 · 논문 선택

관심 논문을 비교하고 원문과 선행연구를 읽습니다. 입력, 출력, 핵심 기여를 정리해 팀의 논문을 정하세요.

02

논문 발표

문제와 가정, 핵심 방법, 실험 결과, 한계를 연결해 설명합니다. 논문의 주장과 팀의 해석을 구분하세요.

03

프로젝트 페이지 공유

핵심 방법의 설명을 페이지에 남기고, 발표 피드백을 반영합니다. 팀원별 기여와 인용 출처도 기록하세요.

어떤 논문을 고르면 좋을까요?

  • SLAM, Odometry, Mapping, Gaussian Splatting, SfM과 관련된 원 논문을 선택합니다. Localization과 Semantic Mapping도 포함합니다.
  • 선정일 기준 최근 36개월 이내 논문을 원칙으로 합니다. 세부 선정 기준과 발표 일정은 수업 공지를 따릅니다.
  • 관련 선행연구를 함께 읽어보세요. 대규모 모델 재학습은 필수가 아닙니다.

학생 페이지에서 설명할 내용

문제와 조건

무엇을 입력받고 무엇을 추정하나요? 센서, 카메라 보정, 장면의 정적·동적 가정은 무엇인가요?

핵심 방법

대표 수식이나 알고리즘을 하나 골라 기호를 정의하세요. 작은 수치 예, 직접 그린 도식, 단계별 결과로 계산 과정을 보여주세요.

주장과 실험 근거

주장을 뒷받침하는 figure 또는 table의 번호를 적으세요. 데이터, metric, 비교 조건이 같을 때와 다를 때를 구분하세요.

한계와 검토

소규모 재현 또는 figure audit로 핵심 주장을 살펴보세요. 실패 조건과 후속 연구 질문을 쓰고, 팀의 추론임을 표시하세요.

동료가 생각해 볼 문제

입력이나 가정을 바꾸면 결과가 어떻게 달라질지 먼저 생각하게 하고, 근거와 해설을 보여주세요. 코드 실행 없이 구성해도 됩니다.

출처와 팀원 기여

논문, 코드, 그림의 출처와 원문의 절·식·그림 번호를 남기세요. 각 팀원의 분석·제작 기여와 피드백 반영 내용을 적으세요.

선택한 논문으로 페이지를 시작하세요

논문 상세 창에서 ‘학생 페이지 양식’을 누르면 해당 논문의 제목과 출처가 입력됩니다. 내용을 작성한 뒤 HTML 또는 Markdown으로 내려받을 수 있습니다.

빈 양식 열기 ↗

발표 일정, 제출 기한, 성적 배점, 중복 논문 배정은 교수자의 별도 공지를 따릅니다.
