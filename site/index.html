COURSE NOTICE · 2026.11.23

기말 프로젝트 진행 안내

Proposal을 먼저 제출하고, 팀별 발표와 피드백을 통해 프로젝트 페이지를 완성합니다. 최종 제출 후에는 서로의 페이지를 읽고 평가합니다.

Proposal 영상 제출 · 13주차까지

12주차에 안내한 Proposal 영상을 아직 제출하지 않은 팀은 13주차까지 제출해 주세요. 팀당 약 10분 분량으로 촬영해 YouTube에 업로드한 뒤, 이 사이트의 Proposal 제출에서 자기 팀을 선택하고 제출자 이름과 영상 링크를 입력하세요. YouTube 영상은 ‘일부 공개’로 설정해도 됩니다.

  • 팀원 및 선정 논문
  • 논문을 선정한 이유, 논문이 다루는 문제와 핵심 아이디어
  • 프로젝트 페이지에서 설명할 내용과 구성 계획
  • 팀원별 역할과 진행 일정

이 단계에서 프로젝트 페이지가 완성되어 있을 필요는 없습니다. 그림, 예시, 시각화 등을 이용해 핵심 내용을 어떻게 설명할지 제안하면 됩니다. 기존 ‘프로젝트 페이지 링크’ 칸에 등록한 YouTube 영상은 Proposal로 반영했습니다. 제출 현황에서 확인하고, 영상이 바뀌었을 때만 링크를 수정해 주세요. 이후 프로젝트 페이지에도 같은 영상 링크를 추가해 주세요.

Proposal 영상 링크 등록

논문 발표와 프로젝트 설명 · 13–15주차

팀당 30분씩 오프라인으로 논문 발표와 프로젝트 설명을 진행합니다. 논문의 핵심 내용과 프로젝트 페이지의 현재 구현 내용, 앞으로 보완할 내용을 함께 소개해 주세요.

  • 13주차: 3팀 발표 예정
  • 14주차: 3팀 발표 예정
  • 15주차: 4팀 발표 예정

세부 발표 순서는 별도로 안내합니다. 발표 후에도 질문과 피드백을 반영하여 프로젝트 페이지를 계속 수정할 수 있습니다.

프로젝트 페이지 최종 제출 · 15주차 종료 시점

15주차 종료 시점까지 프로젝트 페이지를 완성하고, 프로젝트 페이지 제출에서 팀이 직접 만든 페이지의 최종 링크를 등록하거나 갱신해 주세요. 먼저 발표한 팀도 같은 시점까지 수정할 수 있습니다.

페이지에는 논문 정보, 핵심 문제와 방법에 대한 설명, 이해를 돕는 그림·예시·시각화, 참고자료, 팀원별 기여 내용을 포함하세요. Proposal 영상 링크와 발표자료도 함께 정리해 주세요.

프로젝트 페이지 구성 안내

상호평가 · 15주차 종료 후부터 16주차까지

최종 제출 후 다른 팀의 프로젝트 페이지를 읽고 상호평가를 진행합니다. 설명의 정확성, 이해하기 쉬운 정도, 핵심 아이디어를 전달하는 구성, 페이지의 완성도를 살펴봅니다.

평가 대상과 제출 방법, 평가표는 별도로 안내합니다. 16주차까지 상호평가를 마무리하고, 담당 교수의 평가와 함께 기말 프로젝트 점수에 반영합니다.

FINAL PROJECT

읽기에서 설명으로

논문 한 편의 핵심 계산이나 아이디어를 골라, 동료가 입력부터 결과까지 따라갈 수 있도록 설명합니다.

01

2인 팀 · 논문 선택

관심 논문을 비교하고 원문과 선행연구를 읽습니다. 입력, 출력, 핵심 기여를 정리해 팀의 논문을 정하세요.

02

논문 발표

문제와 가정, 핵심 방법, 실험 결과, 한계를 연결해 설명합니다. 논문의 주장과 팀의 해석을 구분하세요.

03

프로젝트 페이지 공유

핵심 방법의 설명을 페이지에 남기고, 발표 피드백을 반영합니다. 팀원별 기여와 인용 출처도 기록하세요.

어떤 논문을 고르면 좋을까요?

  • SLAM, Odometry, Mapping, Gaussian Splatting, SfM과 관련된 원 논문을 선택합니다. Localization과 Semantic Mapping도 포함합니다.
  • 선정일 기준 최근 36개월 이내 논문을 원칙으로 합니다. 세부 선정 기준과 발표 일정은 수업 공지를 따릅니다.
  • 관련 선행연구를 함께 읽어보세요. 대규모 모델 재학습은 필수가 아닙니다.

학생 페이지에서 설명할 내용

문제와 조건

무엇을 입력받고 무엇을 추정하나요? 센서, 카메라 보정, 장면의 정적·동적 가정은 무엇인가요?

핵심 방법

대표 수식이나 알고리즘을 하나 골라 기호를 정의하세요. 작은 수치 예, 직접 그린 도식, 단계별 결과로 계산 과정을 보여주세요.

주장과 실험 근거

주장을 뒷받침하는 figure 또는 table의 번호를 적으세요. 데이터, metric, 비교 조건이 같을 때와 다를 때를 구분하세요.

한계와 검토

소규모 재현 또는 figure audit로 핵심 주장을 살펴보세요. 실패 조건과 후속 연구 질문을 쓰고, 팀의 추론임을 표시하세요.

동료가 생각해 볼 문제

입력이나 가정을 바꾸면 결과가 어떻게 달라질지 먼저 생각하게 하고, 근거와 해설을 보여주세요. 코드 실행 없이 구성해도 됩니다.

출처와 팀원 기여

논문, 코드, 그림의 출처와 원문의 절·식·그림 번호를 남기세요. 각 팀원의 분석·제작 기여와 피드백 반영 내용을 적으세요.

선택한 논문으로 페이지를 시작하세요

논문 상세 창에서 ‘학생 페이지 양식’을 누르면 해당 논문의 제목과 출처가 입력됩니다. 내용을 작성한 뒤 HTML 또는 Markdown으로 내려받을 수 있습니다.

빈 양식 열기 ↗
